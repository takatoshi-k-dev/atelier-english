There is / There are

Atelier English  /  07
Today's Goal
I can use "there is" and "there are"
to say and ask what is in a place.
"there is" と "there are" を使って、ある場所に何があるかを言ったり尋ねたりできる。

When to Use
There is を使うとき
特定しない
特定する
There is a box on the desk.
机の上に箱がある。
The box is on the desk.その箱は机の上にある。
There is a famous tower near Asakusa.
浅草の近くに有名なタワーがある。
Tokyo Skytree is near Asakusa.東京スカイツリーは浅草の近くにある。
There is a house near the station.
駅の近くに家がある。
My house is near the station.私の家は駅の近くにある。
There is の後ろには、ふつう特定しないものが来る
Atelier English  /  07
Negative
否定文の作り方
There is not（= isn't） a box on the desk.
机の上に箱はない。
There are not any（= aren't） some boxes on the desk.
机の上に箱は1つもない。
Atelier English  /  07
Question
疑問文の作り方と答え方
​There is a box on the desk.
机の上に箱はありますか。
Yes, there is. / No, there isn't.
​There are some boxes on the desk.
机の上に箱はありますか。
Yes, there are. / No, there aren't.
